# Todolist

Todolist is a Minecraft Java mod which introduces a text preview system to the game.

## File Folder

```yml
{version folder}
├── config
│   └── todolist-common.toml     # Client config    
│
├── data/todolist                # Store text files
│   ├── default.md
│   ├── test.txt
│   └── ...
└── ...
```
